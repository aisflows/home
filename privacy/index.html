Privacy

Privacy information

This page describes the current Home request and browser analytics behavior. It is a factual product note and makes no legal or compliance claims.

Project requests

The Start a Project form sends data through Formspree only after you submit it. The submitted fields can include request type, optional summary, preferred contact method, email or Telegram contact, and an optional materials URL.

The same information can be sent through the visible email fallback instead. In that case, your mail application handles the message.

Browser analytics

Home uses Umami for browser analytics. The current event contract can include page identity, locale, action or object identifiers, result state, and destination host.

Request text, contact values, materials URLs, credentials, and secrets are excluded from the analytics payload.

Account and choice

No account is required to read the public Home, view the course preview, open public releases, or send a project request.

You can avoid the request form and use the published email link. Do not include private material in a public materials URL.
